# Support

## Pre-alpha phase

Usina Docs is not yet installable and no production support is currently offered for the software itself. The repository is open for architectural discussion, documentation improvements and early contribution proposals.

## Community questions

Use GitHub Issues for reproducible bugs, feature proposals and documentation problems. Search existing Issues before opening a new one and provide enough context for others to understand the request.

Public Issues must not contain passwords, tokens, private configuration, personal data or vulnerability details. Security matters must follow [SECURITY.md](SECURITY.md).

## Commercial services

Usina.BR may offer implementation, migration, integration, training, consulting, hosting and support services independently from the open source license. No commercial contract is required to exercise rights granted by the MPL-2.0.

Service availability, response times and contractual terms are not implied by this community support document.
