# Usina Docs

Usina Docs is an open source platform for knowledge management, controlled documentation and training.

Usina Docs e uma plataforma open source para gestao de conhecimento, documentacao controlada e treinamento.

## Documentation

- [Portugues do Brasil](README.pt-BR.md)
- [English](README.en.md)

## Project status

Usina Docs is in **pre-alpha**. Its first installable foundation is available for local evaluation only and is not ready for production use.

The AdvPL Guide is the first real-world use case and the laboratory where the product requirements are being validated. Usina Docs itself remains independent from AdvPL, Protheus and TOTVS-specific concepts.
