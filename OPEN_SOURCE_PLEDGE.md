# Usina Docs Open Source Pledge

**Usina.BR Tecnologia e Informação Ltda. ME**, maintainer of the Usina Docs project, publicly commits to keeping the official Usina Docs source code open source.

This is a permanent principle of the project.

## Our commitment

Usina Docs was created as an open source project and will be maintained as such.

Usina.BR commits to:

- keep the source code of the official project publicly available;
- allow its study, use, modification and redistribution under the applicable open source license;
- allow commercial use of the software;
- allow Usina Docs to be used or integrated into commercial and proprietary solutions, subject to the obligations of the applicable license;
- keep official versions of the project under an open source license;
- preserve the history and attribution of community contributions.

## Open software and commercial services

Open source software does not require all related services to be free of charge.

Usina.BR may commercially provide support, implementation, training, consulting, development, integrations, hosting and other services related to Usina Docs.

These services are independent from the software license. No commercial contract is required to exercise the rights granted by the project's open source license.

## Ecosystem

Companies and developers may build products, integrations and services using Usina Docs.

Usina.BR does not intend to control the licensing of independent software built around the project beyond the obligations applicable to code covered by the MPL-2.0.

## Continuity

This document represents a public commitment by Usina.BR to the philosophy of the project.
